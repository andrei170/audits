What to look at in each one
  • The first line. Does it name the job and the area straight away?
  • The picture. Real vans and real people, or a stock photo?
  • “Started running on” near the top of each advert. Firms switch off adverts that bring nobody, so one that has been running for weeks is usually getting applicants.
  • Where the button goes. A form on Facebook, or a careers page on the firm’s own site like the one we built for you.
If a link shows nothing

Adverts end. If one has finished, Meta may show it as inactive or not show it at all. We can pull up live ones together on the call.
